# Kokeb Excellence Language Academy

A conversion focused website for live one to one Ethiopian language lessons for learners ages 8 and above.

## Live website

https://kokeb-excellence-language.vercel.app

## What it includes

* One to one Amharic, Tigrinya, Afaan Oromo and other Ethiopian language classes
* Young teachers and flexible family scheduling
* One week free trial contact flow
* Family story and testimonial pages
* Light and dark themes
* Responsive design for phones, tablets and computers

Built with Next.js, React and TypeScript.
